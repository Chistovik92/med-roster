# История изменений

Все заметные изменения в этом проекте документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.7.0] - 2026-11-16

### Новое
- **Полная документация API для интеграции со сторонними программами** (API_INTEGRATION.md):
  полная спецификация всех REST-эндпоинтов, форматов JSON, кодов ошибок, примеров на Python
  для 1С, внешних систем учёта времени, отчётности и автоматизации.
- Экспорт/импорт всей базы месяцев (GET /api/saved/export, POST /api/saved/import):
  передача med-roster.db между установками, миграция данных, резервное копирование.
- Переименование сохранённых месяцев (POST /api/saved/{id}/rename):
  человекочитаемые заголовки вместо автоматических дат.
- Эндпоинт PATCH /api/saved/{id} для обновления сохранённого месяца из текущей сессии.

### Улучшено
- Автокоррекция (POST /api/session/{sid}/autocorrect) теперь возвращает структурированный
  список исправлений fixes[] с кодами, сотрудниками, днями и сообщениями.
- Экспорт .xls (GET /api/export/xls/{sid}) корректно формирует колонки итогов
  по длине месяца (28-31 день), файл валидно импортируется обратно.
- Центр обновлений (/api/maintenance*) показывает совместимые версии зависимостей
  через packaging.version, безопасное обновление без слома совместимости.

### Исправлено
- Утечка памяти в _sessions: добавлен TTL 30 мин и лимит 8 сессий с LRU-вытеснением.
- Крах portable-сборки на Windows 7 в GUI-режиме: sys.stdout/stderr=None -> перенаправление в os.devnull до импорта uvicorn.
- Кодировка имени установщика Windows: -INPUTCHARSET UTF8 + UTF-8 BOM в NSIS-скрипте.

## [0.6.2] - 2026-11-16

### Новое
- **Windows 7 SP1: DLL load failed while importing _socket (ERROR_INVALID_PARAMETER).**
  Причина - отсутствие KB2533623: вызов LoadLibraryEx с флагами
  LOAD_LIBRARY_SEARCH_* требует этого обновления, без него Python не может
  загрузить системные DLL.
- KB2533623 (x86 и x64, официальные MSU, подпись Microsoft, зафиксирован SHA256)
  включены внутри portable ZIP и установщика - скачивание с серверов MS не требуется.
- run.py проверяет наличие KB при старте (SetDefaultDllDirectories);
  при отсутствии предлагает установить через wusa.exe с проверкой SHA256.
  После установки - перезапуск приложения. Больше не нужен ручной поиск KB.
- Центр обновлений показывает статус KB на Windows 7.
- CI проверяет наличие обоих MSU в release ZIP; test_win7_prereq.py проверяет SHA256.

### Улучшено
- app/core/win7_prereq.py - проверка и установка KB2533623.
- packaging/windows/Windows6.1-KB2533623-{x86,x64}.msu - официальные MSU.
- Тест test_win7_prereq.py (SHA256, проверка spec/workflow).

## [0.6.0] - 2026-11-16

### Новое
- **Автокоррекция графика** в POST /api/session/{sid}/autocorrect:
  норма 588н, сумма, точные дубликаты, сокращение предпраздничной смены.
  Накладки ставок и неизвестные должности не угадываются.
- **Экспорт .xls** (xlwt) + GET /api/export/xls/{sid}.
  Колонки итогов берутся по длине месяца, поэтому .xls корректно

  сохранение месяца, сериализация и список сохранённых.
- Новые тесты test_autocorrect.py, test_xls_export.py; всего 14 тестов,
  HTTP e2e (autocorrect + XLS + dept), node --check и git diff --check.

### Исправлено
- **Windows 7 portable: крах _socket.** Анализ release ZIP 0.5.5 показал
  отсутствие UCRT, от которого зависят _socket.pyd и другие модули.
  medgrafik.spec включает ucrtbase.dll и api-ms-win-crt-*.dll
  из Windows SDK x86, CI проверяет их наличие. Python 3.8.10 x86 + PyInstaller 4.10 сохранены.

## [0.5.5] - 2026-11-16

### Новое
- **Установка Linux одной командой**: install.sh устанавливает/обновляет
  программу, создаёт ~/.local/share/med-roster, virtualenv,
  ~/.local/bin/med-roster и ярлык меню. Сохранённые месяцы при обновлении сохраняются.
- **Компактная таблица**: вспомогательные блоки сворачиваются, таблица занимает

  Ф.И.О. и должность закреплены при горизонтальной прокрутке.
- **Контекст ошибок запуска**: run.py показывает тип и текст ошибки, путь к журналу
  и версию Python; импорты приложения перенесены внутрь обработчика.

### Исправлено
- **Windows 7 portable _socket**: первая попытка исправления (Python 3.8.10 x86,
  PyInstaller 4.10) не решила проблему на целевом Windows 7 - смены toolchain
  оказалось недостаточно; окончательное дополнение UCRT сделано в 0.6.0.
- В таблице неверные дни подсвечены, над ней выводятся сотрудник/день/причина;
  список ошибок кликабелен и ведёт к ячейке/строке.

## [0.4.5] - 2026-11-14

### Новое
- **Выключение сервиса**: кнопка в шапке UI + POST /api/shutdown. Остановка -
  os._exit(0) в daemon-потоке после SHUTDOWN_DELAY = 0.5. Работает во всех
  режимах: run.py, PyInstaller GUI-сборка, uvicorn из start.bat/start.sh.
- Скрипты stop.bat (Windows: netstat+taskkill) и stop.sh (Linux: fuser/lsof)

- **Защита от повторного запуска** в run.py: проверка /api/health, диалог
  "Да/Нет" (MessageBox/input), убийство процесса на порту. В start.bat/start.sh
  - аналогичное предупреждение.
