# Журнал изменений

Все заметные изменения проекта фиксируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] — 2026-11-14

### Добавлено
- **Установщики для разных систем** (`packaging/`):
  - Windows 7/10/11 — автономное приложение (PyInstaller) + установщик NSIS
    `MedGrafik-Setup-*.exe` (ставится в профиль пользователя без прав
    администратора);
  - Debian/Ubuntu — пакет `.deb`;
  - Fedora / Simply Linux и др. — пакет `.rpm`;
  - любой Linux — переносимый архив `.tar.gz`.
- Автоматическая сборка установщиков и публикация релиза в GitHub Actions
  (`.github/workflows/release.yml`) при публикации тега `v*`.
- Лаунчер `run.py` (прямой запуск и для PyInstaller): открывает браузер,
  пишет ошибки в журнал и показывает окно об ошибке в GUI-режиме.
- Иконка приложения для Linux (`.desktop` + SVG).

### Оптимизировано (под слабое железо 2009+)
- Фронтенд: после первого импорта таблица сотрудников обновляется
  **инкрементально** — перерисовываются только изменённые строки, а не все
  ~4500 ячеек на каждое изменение (раньше каждая правка вызывала полную
  перерисовку).
- Бэкенд: импорт `.xls` теперь читает файл из памяти (`file_contents`), без
  записи во временный файл — меньше операций с диском и нет проблем с
  блокировкой файлов на Windows.

### Исправлено
- Баг в `_to_str`: мёртвая проверка NaN (`value != value`) заменена на
  корректную; числовая пустая ячейка `0.0` больше не попадает в ФИО.
- Версия приложения вынесена в единую точку (`app.__version__`) и больше не
  захардкожена в `main.py`.
- Утечка памяти: сессии импорта теперь ограничены (8 штук, TTL 30 минут) —
  сервер не растёт в памяти при длительной работе.
- В подвале интерфейса убрано неверное упоминание SQLite (приложение не
  использует БД).

## [0.1.0] — 2026 (первый релиз)

- Производственный календарь РФ на любой год (1990–2050), точный для 2020–2027.
- Расчёт норм по Приказу № 588н (30/33/36/39/40 ч, доли ставки, неявки).
- Импорт `.xls` (xlrd), классификация должностей, валидатор 5 типов ошибок.
- Веб-интерфейс (FastAPI + vanilla JS): редактирование ячеек, автосмены,
  копирование графика, «светофор».
- Экспорт CSV, Т-13, ОКУД 0504421, график на подпись.
