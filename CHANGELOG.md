# Журнал изменений

Все заметные изменения проекта фиксируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

## [0.6.4] — 2026-11-16

### Улучшено
- **Крупный редактор ячейки:** увеличен размер до 400×180px, шрифт 24px жирный —
  значение времени теперь отчётливо видно даже на экранах 1366px.
- **Синхронизация сохранения месяца:** кнопка «Сохранить месяц» теперь обновляет
  выбранный в списке месяц вместо создания нового. Если месяц загружен из
  «Сохранённых месяцев», повторное нажатие обновит эту же запись в базе, а не
  создаст дубликат.
- **Экспорт базы с датой:** файл базы теперь скачивается с осмысленным именем
  вида `med-roster-2026-11-16.db` вместо `export` или `med-roster.db`.

### Добавлено
- API `PATCH /api/saved/{id}` — обновление данных сохранённого месяца из текущей
  сессии.
- `storage.update_saved()` — обновление записи в БД без создания новой.
- Поле `savedId` в `currentData` (фронтенд) — отслеживание привязки к сохранённой
  записи.

### Исправлено
- Баг повторного создания записи при многократном нажатии «Сохранить месяц» для
  одного и того же месяца.

## [0.6.3] — 2026-11-16

### Добавлено
- **Крупный редактор ячейки:** при выборе ячейки для ввода времени открывается
  отдельное плавающее поле большого размера рядом с ячейкой. Значение видно
  целиком и удобно редактируется, при этом таблица месяца остаётся на экране.
- **Сохранённые месяцы:** кнопка «Сохранить месяц» в блоке «Источник данных»,
  кнопка «Сохранить базу (копия)» для выгрузки всей базы в указанное место,
  переименование месяца в списке и подгрузка сторонней базы `med-roster.db`.
- Локальная база в portable/установленной сборке хранится **рядом с программой**
  (для переноса вместе с папкой); в исходниках — каталог данных пользователя.
- Импорт/объединение базы из внешнего расположения (по содержимому, без дублей).

### Изменено
- Оптимизация ввода под слабые ПК: меньше перерисовок, плавающий редактор не
  изменяет ширину таблицы.

## [0.6.2] — 2026-11-16

### Исправлено
- **Windows 7 SP1: `DLL load failed while importing _socket` (ERROR_INVALID_PARAMETER).**
  Причина — отсутствие **KB2533623**: без него `LoadLibraryEx` не поддерживает
  флаги `LOAD_LIBRARY_SEARCH_*`, которые использует Python при загрузке DLL.
- KB2533623 (**x86 и x64**, подпись Microsoft, проверка SHA256) теперь включён
  **внутрь portable ZIP и установщика** — скачивать с серверов Microsoft не нужно.
- `run.py` перед запуском проверяет наличие KB (`SetDefaultDllDirectories`);
  при отсутствии — автоматическая тихая установка через `wusa.exe`.
  При невозможности установки показывается понятное сообщение с инструкцией.
- Центр «Обновления» на Windows 7 показывает статус KB2533623.
- CI проверяет наличие обоих MSU в release ZIP.

### Добавлено
- `app/core/win7_prereq.py` — проверка и установка KB2533623.
- `packaging/windows/Windows6.1-KB2533623-{x86,x64}.msu` — официальные пакеты.
- Тест `test_win7_prereq.py` (SHA256, наличие в spec/workflow).

## [0.6.1] — 2026-11-16

### Добавлено
- **Центр «Обновления»** в шапке: проверка последней версии программы на GitHub
  и состояния необходимых компонентов.
- **Установка обновления из портативной Windows-сборки**: скачивается

## [0.6.0] — 2026-11-16

### Добавлено
- **Кнопка «Исправить ошибки автоматически»** и `POST /api/session/{sid}/autocorrect`:
  вычисляет норму по 588н, исправляет итоговую сумму, удаляет точные дубликаты
  и сокращает найденные предпраздничные смены на 1 час. Пересечения ставок и
  неизвестные должности намеренно остаются на ручную проверку.
- **Экспорт исправленного графика в бинарный `.xls`** (`xlwt`), кнопка
  «График (.xls)» и `GET /api/export/xls/{sid}`. Поддерживается повторный импорт,
  включая месяцы с 31 днём.
- **Поле «Подразделение»** в шапке UI: передаётся в `.xls`, Т-13, ОКУД 0504421
  и график на подпись, запоминается в браузере и в сохранённых месяцах.
- Проверки `test_autocorrect.py` и `test_xls_export.py`; HTTP e2e для
  автокоррекции, XLS и подразделения.

### Исправлено
- **Windows 7 portable: повторный сбой `_socket`.** Анализ release ZIP 0.5.5
  показал отсутствие Universal CRT. В сборку теперь включаются `ucrtbase.dll`
  и `api-ms-win-crt-*.dll` из Windows SDK x86; CI проверяет их наличие в ZIP.

## [0.5.5] — 2026-11-16

### Добавлено
- **Установка на Linux одной командой** из репозитория: `install.sh` загружает
  актуальную версию, создаёт virtualenv, команду `med-roster` и ярлык меню.
- **Ошибка прямо у таблицы.** Для неверной ячейки показываются сотрудник, день
  и причина; ошибки в общем списке кликабельны и переводят к нужному месту.
- Сообщение об ошибке запуска теперь содержит тип и текст исключения, путь к
  журналу и версию Python, а не только общую фразу о сбое.

### Изменено
- **Компактный график на весь экран.** Вспомогательные блоки сворачиваются,
  дни месяца помещаются в ширину рабочей области на стандартных мониторах,
  Ф.И.О. и должность закреплены при горизонтальной прокрутке, а таблица
  использует высоту окна.

### Исправлено
- **Windows 7 portable: `DLL load failed while importing _socket`.** Сборка
  переведена на Python 3.8.10 x86 и PyInstaller 4.10; 32-разрядный вариант
  работает и на 32-, и на 64-разрядных Windows 7/10/11.

## [0.5.0] — 2026-11-15

### Добавлено
- **График открывается сразу при запуске.** Автоматически создаётся пустой график
  на текущий месяц — можно сразу добавлять сотрудников и вносить смены. Импорт
  `.xls`, загрузка сохранённого месяца и генерация остаются доступны.
- **Удобная навигация по таблице.** Заголовки дней показывают день недели и число;
  выходные и праздники подсвечены, сокращённые предпраздничные дни отмечены
  отдельно. Enter сохраняет и переводит на строку ниже, Tab — вправо, стрелки
  перемещают выделение по ячейкам.
- **Горячие клавиши для выделенной ячейки:** `1`/`2` — утренняя/вечерняя типовая
  смена с учётом недельной нормы сотрудника, `В`/`О`/`Б`/`У` — коды состояний.
- **Быстрые типовые смены** в блоке «Инструменты» и **массовое добавление
  сотрудников** списком «Ф.И.О.; должность; ставка» одним запросом.

### Исправлено
- Документация приведена в соответствие с поставленным MVP: обновлены README,
  руководства пользователя, перечень тестов и пояснения к целевой архитектуре.
- Единообразное отображение доли ставки (`0,50` вместо `0,5`).

## [0.4.5] — 2026-11-14

### Добавлено
- **Выключение сервиса.** Кнопка «Выключить сервис» в шапке интерфейса и эндпоинт
  `POST /api/shutdown` корректно завершают сервер (во всех режимах запуска:
  `run.py`, PyInstaller GUI-сборка, `uvicorn` из `start.bat`/`start.sh`).
- **Скрипты остановки** `stop.bat` (Windows) и `stop.sh` (Linux): находят процесс
  на порту 25625 и завершают его — работают с любой версией, даже если в старой
  нет кнопки «Выключить».
- **Защита от повторного запуска.** При запуске, если на порту 25625 уже работает
  другая версия программы, лаунчер (`run.py`) обнаруживает её и предлагает
  остановить (диалог «Да/Нет») и продолжить запуск — вместо непонятной ошибки
  «address already in use». В `start.bat`/`start.sh` добавлено такое же
  предупреждение.

### Исправлено
- Запуск новой версии больше не падает с ошибкой при уже запущенной предыдущей
  (0.3.0 / 0.4.0): вместо трассировки uvicorn пользователь получает понятное
  сообщение и возможность остановить старую версию в один шаг.

## [0.4.0] — 2026-11-14

### Добавлено
- **Ручной ввод всего графика.** Новый источник данных «Новый график вручную»:
  создаётся пустой график на любой месяц, затем добавляются сотрудники
  (Ф.И.О., должность, ставка), а ячейки заполняются по клику (как и при импорте).
- **Редактирование доли ставки** (1,00 / 0,75 / 0,50 / 0,25) и недельной нормы
  прямо в таблице: Ф.И.О., должность, ставка и норма — редактируемые ячейки.
  При смене должности норма пересчитывается автоматически (её можно задать вручную).
- **Валидация ручного ввода.** Для строк без колонки «Прим.» расчётная месячная
  норма считается автоматически по Приказу № 588н (недельная норма × ставка) и
  сравнивается с фактической суммой часов — расхождения попадают в «Ошибки».
- **Сохранение месяца.** Кнопка «Сохранить месяц» пишет график в локальную базу
  SQLite (stdlib, без новых зависимостей): Windows — `%APPDATA%\med-roster`,
  Linux — `~/.local/share/med-roster` (переопределяется `MEDROSTER_DATA_DIR`).
- **Генерация следующих месяцев.** Из текущего (или сохранённого) графика можно
  сгенерировать любой следующий месяц: переносится состав сотрудников и, по
  желанию, смены по дням недели (самая частая смена каждого дня недели).
- **Удобнее интерфейс:** единая вкладка «График» с источником данных, список
  сохранённых месяцев, добавление/удаление сотрудников, редактирование мета-полей.

### Изменено
- Сводка показывает период и признак «вручную»; для ручных графиков скрывается
  колонка «Сумма», а «Прим.» показывает расчётную норму.

## [0.3.0] — 2026-11-14

### Добавлено
- **Поле «Учреждение»** в шапке интерфейса: введённое название медицинского
  учреждения подставляется во все печатные формы (Т-13, ОКУД 0504421, график на
  подпись) и запоминается в браузере (`localStorage`). По умолчанию —
  «ГУЗ «СГП № 16»». Название вынесено в единую константу `DEFAULT_ORG`.

### Исправлено
- **Критично: портативная Windows-сборка не запускалась.** В GUI-сборке
  PyInstaller (`console=False`) потоки `sys.stdout`/`sys.stderr` равны `None`,
  из-за чего uvicorn падал на `sys.stdout.isatty()` с ошибкой
  «Unable to configure formatter 'default'». Теперь отсутствующие потоки
  перенаправляются в `os.devnull` перед запуском сервера.
- **Кракозябры в названии установщика Windows.** Скрипт NSIS был в UTF-8 без
  BOM, и `makensis` читал его в системной кодировке (CP1252), ломая
  «МедГрафик: Поликлиника». Добавлены флаг `-INPUTCHARSET UTF8` и UTF-8 BOM.
- **Детерминированная кодировка Linux-сборки:** в CI-шаг сборки пакетов добавлены
  `LANG`/`LC_ALL=C.UTF-8`.
- Строка «УТВЕРЖДАЮ» в графике на подпись теперь выводит «Главный врач <учреждение>»
  (не зашито конкретное ФИО и учреждение).
- `tests/test_calendar_rf.py` теперь завершается с ненулевым кодом при провале
  (раньше регрессии в календаре не останавливали CI).

## [0.2.0] — 2026-11-14

### Добавлено
- **Установщики для разных систем** (`packaging/`):
  - Windows 7/10/11 — автономное приложение (PyInstaller) + установщик NSIS
    `MedGrafik-Setup-*.exe` (ставится в профиль пользователя без прав
    администратора);
  - Debian/Ubuntu — пакет `.deb`;
  - Fedora / Simply Linux и др. — пакет `.rpm`;
  - любой Linux — переносимый архив `.tar.gz`.
- Автоматическая сборка установщиков и публикация релиза в GitHub Actions
  (`.github/workflows/release.yml`) при публикации тега `v*`.
- Лаунчер `run.py` (прямой запуск и для PyInstaller): открывает браузер,
  пишет ошибки в журнал и показывает окно об ошибке в GUI-режиме.
- Иконка приложения для Linux (`.desktop` + SVG).

### Оптимизировано (под слабое железо 2009+)
- Фронтенд: после первого импорта таблица сотрудников обновляется
  **инкрементально** — перерисовываются только изменённые строки, а не все
  ~4500 ячеек на каждое изменение (раньше каждая правка вызывала полную
  перерисовку).
- Бэкенд: импорт `.xls` теперь читает файл из памяти (`file_contents`), без
  записи во временный файл — меньше операций с диском и нет проблем с
  блокировкой файлов на Windows.

### Исправлено
- Баг в `_to_str`: мёртвая проверка NaN (`value != value`) заменена на
  корректную; числовая пустая ячейка `0.0` больше не попадает в ФИО.
- Версия приложения вынесена в единую точку (`app.__version__`) и больше не
  захардкожена в `main.py`.
- Утечка памяти: сессии импорта теперь ограничены (8 штук, TTL 30 минут) —
  сервер не растёт в памяти при длительной работе.
- В подвале интерфейса убрано неверное упоминание SQLite (приложение не
  использует БД).

## [0.1.0] — 2026 (первый релиз)

- Производственный календарь РФ на любой год (1990–2050), точный для 2020–2027.
- Расчёт норм по Приказу № 588н (30/33/36/39/40 ч, доли ставки, неявки).
- Импорт `.xls` (xlrd), классификация должностей, валидатор 5 типов ошибок.
- Веб-интерфейс (FastAPI + vanilla JS): редактирование ячеек, автосмены,
  копирование графика, «светофор».
- Экспорт CSV, Т-13, ОКУД 0504421, график на подпись.
