# med-roster — Инструкция пользователя

> [English version](USAGE.md)

Как установить, запустить и пользоваться программой **med-roster
(«МедГрафик: Поликлиника»)** для расчёта графиков сменности и табелей рабочего
времени (ОКУД 0504421 / Т-13).

---

## 1. Требования

- Python **3.8+** (работает на Windows 7 и Linux Debian 11–13 / Ubuntu).
- Без Node.js и Docker — программа это один процесс FastAPI с веб-страницей на
  чистом JavaScript. Сохранённые месяцы хранятся в локальной базе SQLite
  (встроенной в Python, без внешних зависимостей).

> **Установщики:** если не хотите ставить Python вручную, скачайте готовый
> установщик из [релиза на GitHub](https://github.com/Chistovik92/med-roster/releases):
> `.exe` для Windows, `.deb`/`.rpm` для Linux. Они собраны автоматически и
> ставятся «в один клик».

## 2. Установка

### Вариант А — готовый установщик (рекомендуется)

- **Windows:** запустите `MedGrafik-Setup-<версия>.exe` — программа установится
  в профиль пользователя, ярлык появится в меню «Пуск» и на рабочем столе.
- **Debian/Ubuntu:** `sudo dpkg -i med-roster_<версия>_amd64.deb` (при установке
  нужен интернет для зависимостей).
- **Fedora/Simply Linux:** `sudo rpm -i med-roster-<версия>.x86_64.rpm`.

**Linux — установка или обновление прямо из репозитория одной командой:**

```bash
curl -fsSL https://raw.githubusercontent.com/Chistovik92/med-roster/master/install.sh | bash
```

После установки запускайте командой `med-roster` или через ярлык в меню приложений.
Скрипт сам загружает код, создаёт virtualenv и устанавливает зависимости. При
отсутствии Python на Debian/Ubuntu, Fedora и других поддерживаемых системах
предложит установить системные пакеты через `sudo`.

### Вариант Б — запуск из исходников

1. Склонируйте репозиторий (или скопируйте папку проекта).
2. Установите зависимости:

   **Windows**
   ```
   py -m pip install -r requirements.txt
   ```

   **Linux**
   ```
   python3 -m pip install -r requirements.txt
   ```

## 3. Запуск

**Windows** — двойной клик по `start.bat` (или запуск из командной строки).

**Linux**
```
chmod +x start.sh
./start.sh
```

Или вручную:
```
python -m uvicorn app.main:app --host 127.0.0.1 --port 25625
```

Веб-панель откроется по адресу **http://127.0.0.1:25625**.

> **Повторный запуск.** Программа занимает порт 25625, поэтому запустить вторую
> копию (или новую версию) одновременно нельзя. Если при запуске появляется
> сообщение, что сервис уже запущен, — остановите работающую копию (см. раздел 11)
> и запустите снова. Лаунчер `run.py` при обнаружении уже работающей версии сам
> предложит остановить её и продолжить запуск.

## 4. Интерфейс

В панели две вкладки.

### 4.1. Производственный календарь

- Введите **год** (1990–2050) и нажмите **«Показать»**.
- Появится таблица: по каждому месяцу — рабочие дни, сокращённые
  (предпраздничные) дни и норма часов за месяц для недельных норм
  30 / 33 / 36 / 39 / 40 часов (Приказ № 588н).
- Ниже — норма за год и списки праздничных и сокращённых дней.
- Для годов вне точного диапазона 2020–2027 показывается метка
  **«требует сверки»** (постановления на будущие годы ещё не известны).

### 4.2. Вкладка «График» — источник данных

Вкладка «График» объединяет четыре способа начать работу:

1. **Импорт .xls** — выберите файл формата «СГП №16» и нажмите
   «Импортировать» (период определяется из шапки автоматически).
2. **Новый график вручную** — укажите год и месяц и нажмите «Создать»:
   получится пустой график, в который вы добавляете сотрудников и заполняете
   ячейки (см. раздел 5).
3. **Сохранённые месяцы** — список ранее сохранённых графиков: «Загрузить»
   открывает его, «Удалить» убирает из списка.
4. **Сгенерировать следующий месяц** — из текущего графика создаёт график на
   указанный месяц: переносит состав сотрудников, а при включённой галочке
   «перенести смены по дням недели» — и сами смены (для каждого дня недели
   берётся самая частая смена).

После загрузки/создания/генерации появляются:

- **Сводка** — период, сотрудники, дней в месяце, ошибки, предупреждения.
- **Кнопки экспорта и сохранения** — «Сохранить месяц», CSV, Т-13,
  ОКУД 0504421, график на подпись.
- **Ошибки и предупреждения** — находки валидатора (в т.ч. по ручным данным).
- **Сотрудники** — редактируемая таблица (добавление и удаление сотрудников).
- **Инструменты** — автозаполнение и копирование графика.

### 4.3. Учреждение и подразделение

В шапке панели есть поля **«Учреждение»** и **«Подразделение»**. Введённые
названия подставляются в `.xls` и печатные формы (Т-13, ОКУД 0504421, график на
подпись) и запоминаются в браузере (`localStorage`). Подразделение также
сохраняется вместе с месяцем. Учреждение по умолчанию — «ГУЗ «СГП № 16»».

## 5. Редактирование графика

**Таблица открывается сразу при запуске** — автоматически создаётся пустой график
на текущий месяц, так что можно сразу вносить данные. Если нужен другой месяц,
другой источник (импорт `.xls`, сохранённый месяц, генерация) — выберите его в
карточке «Источник данных» выше.

- **Компактный вид.** Источники данных, сводка, ошибки и инструменты сворачиваются;
  таблица занимает рабочую область окна. На стандартном мониторе месяц помещается
  по ширине; при недостатке места Ф.И.О. и должность остаются закреплёнными.
- **Заголовки дней** показывают день недели и число («Пн 1», «Вт 2»…). Выходные
  и праздники подсвечены серым, предпраздничные (сокращённые) дни — зелёной
  чертой снизу.
- **Где и в чём ошибка.** Неверная ячейка подсвечивается, а над таблицей
  выводятся сотрудник, день и причина. Нажатие на запись в списке «Ошибки и
  предупреждения» переводит к нужной ячейке или строке.
- **«Исправить ошибки автоматически»** в блоке ошибок: пересчитывает норму по
  588н, выравнивает итоговую сумму, удаляет точные дубликаты и сокращает найденные
  предпраздничные смены на 1 час. Пересечения ставок и неизвестные должности
  остаются на ручную проверку; после автокоррекции проверьте результат.
- **«Исправить ошибки автоматически»** в списке «Ошибки и предупреждения»:
  пересчитывает норму по Приказу № 588н, выравнивает итоговую сумму по фактическим
  часам, удаляет точные дубликаты строк и сокращает найденные предпраздничные
  смены на 1 час. Пересечения интервалов ставок и неизвестные должности остаются
  для ручного решения — после исправления проверьте график перед экспортом.
- **Кликните** по ячейке дня, чтобы изменить значение. Вводите интервал вида
  `8-15,48` или код статуса (`В`, `ОТ`, `Б`, `У`).
- **Горячие клавиши.** Когда ячейка выделена (клик / переход стрелками), но поле
  ввода не открыто: **1** — утренняя смена, **2** — вечерняя (длительность
  подставляется по недельной норме сотрудника), **В** — выходной, **О** — отпуск,
  **Б** — больничный, **У** — учёба. **Enter**/**F2** — открыть ввод вручную,
  **стрелки** — навигация по ячейкам.
- **Enter** в поле ввода — сохранить и перейти к ячейке ниже; **Tab** — вправо;
  **Esc** — отмена.
- **Кликните** по Ф.И.О., должности, ставке или норме, чтобы изменить их.
  Ставка (1,00 / 0,75 / 0,50 / 0,25) и недельная норма выбираются из списка.
  При смене должности норма пересчитывается автоматически (можно задать вручную).
- Чтобы добавить сотрудника, заполните поля «Ф.И.О.», «Должность», «Ставка» и
  нажмите **«Добавить сотрудника»**. Удалить строку — крестик «✕» справа.
- **«Добавить списком…»** — вставьте сразу несколько строк в формате
  «Ф.И.О.; должность; ставка» (ставка необязательна, по умолчанию 1,00) и
  нажмите «Добавить всех».
- После каждого изменения пересчитываются часы, итоги и валидация. Для строк,
  введённых вручную, норма месяца считается по Приказу № 588н автоматически и
  сверяется с фактической суммой часов.
- Нижний **«светофор»** подводит итог:
  - 🟢 **зелёный** — ошибок нет, можно выгружать;
  - 🟡 **жёлтый** — только предупреждения, выгружать можно;
  - 🔴 **красный** — остались ошибки, исправьте и выгрузите заново.

## 6. Сохранение и генерация месяцев

### Сохранение месяца
Нажмите **«Сохранить месяц»** в сводке. График запишется в локальную базу SQLite:

- Windows — `%APPDATA%\med-roster`;
- Linux — `~/.local/share/med-roster`;
- переопределение — переменная окружения `MEDROSTER_DATA_DIR`.

### Генерация следующих месяцев
1. Откройте/создайте/загрузите график (например, за ноябрь).
2. В блоке «Сгенерировать следующий месяц» укажите год и месяц и включите
   (или выключите) перенос смен по дням недели.
3. Нажмите **«Сгенерировать»** — появится график на новый месяц с тем же
   составом сотрудников. Проверьте его и сохраните.

## 7. Инструменты

### Автозаполнение
Заполнить пустые ячейки сотрудника одной сменой:
1. Выберите сотрудника и введите смену (например, `8-15,48`).
2. Отметьте **«только рабочие дни»**, чтобы заполнять лишь рабочие дни по
   производственному календарю (иначе — все пустые, включая выходные).
3. Нажмите **«Заполнить»**.

### Копирование графика («врач ↔ медсестра»)
1. Выберите сотрудника-источник в поле **«Из»** и приёмника в поле **«В»**.
2. Нажмите **«Скопировать график»**. Весь месяц приёмника перезапишется
   сменами источника.

## 8. Экспорт

Формы скачиваются как XLS, CSV или печатный HTML:

| Кнопка | Формат | Назначение |
| --- | --- | --- |
| График (.xls) | бинарный Excel `.xls` | исправленный график; можно снова импортировать |
| График (CSV) | CSV с `;`-разделителем | исправленный график для Excel |
| Табель Т-13 | печатный HTML | табель учёта рабочего времени Т-13 |
| Табель ОКУД 0504421 | печатный HTML | табель для бюджетных организаций |
| График на подпись | печатный HTML | график на утверждение («УТВЕРЖДАЮ» / «СОГЛАСОВАНО») |

> Печатайте HTML-формы прямо из браузера (Ctrl+P).

## 9. Данные и конфиденциальность

- Персональные данные (152-ФЗ) хранятся **только локально**. Исходные файлы
  `.xls`/`.docx` исключены из git (см. `.gitignore`) и не покидают компьютер.
- Текущая сессия — **в памяти**: при закрытии сервера она удаляется. Чтобы
  продолжить работу позже, нажмите **«Сохранить месяц»** и затем загрузите его.

## 11. Остановка сервиса

Программа работает как фоновый веб-сервер на порту 25625. Чтобы корректно
остановить её (например, перед запуском новой версии):

- **Кнопка «Выключить сервис»** в правом верхнем углу панели — самый простой
  способ. Появится экран «Сервис остановлен», вкладку можно закрыть.
- **`stop.bat`** (Windows) — двойной клик по файлу остановит процесс на порту
  25625.
- **`stop.sh`** (Linux) — `./stop.sh` (использует `fuser`, при его отсутствии —
  `lsof`).

Если сервис запущен старой версией без кнопки «Выключить», используйте
`stop.bat` / `stop.sh` — они работают с любой версией.

> **Зачем это нужно.** Новая версия не может занять порт 25625, пока работает
> старая. Поэтому перед запуском обновления остановите старую копию. Начиная с
> 0.4.5 лаунчер делает это автоматически: обнаруживает работающую копию и
> предлагает остановить её в один шаг.
