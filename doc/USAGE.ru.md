# med-roster — Инструкция пользователя

> [English version](USAGE.md)

Как установить, запустить и пользоваться программой **med-roster
(«МедГрафик: Поликлиника»)** для расчёта графиков сменности и табелей рабочего
времени (ОКУД 0504421 / Т-13).

---

## 1. Требования

- Python **3.8+** (работает на Windows 7 и Linux Debian 11–13 / Ubuntu).
- Без базы данных, без Node.js и Docker — программа это один процесс FastAPI
  с веб-страницей на чистом JavaScript и сессиями в памяти (без SQLite-файлов).

## 2. Установка

1. Склонируйте репозиторий (или скопируйте папку проекта).
2. Установите зависимости:

   **Windows**
   ```
   py -m pip install -r requirements.txt
   ```

   **Linux**
   ```
   python3 -m pip install -r requirements.txt
   ```

## 3. Запуск

**Windows** — двойной клик по `start.bat` (или запуск из командной строки).

**Linux**
```
chmod +x start.sh
./start.sh
```

Или вручную:
```
python -m uvicorn app.main:app --host 127.0.0.1 --port 25625
```

Веб-панель откроется по адресу **http://127.0.0.1:25625**.

## 4. Интерфейс

В панели две вкладки.

### 4.1. Производственный календарь

- Введите **год** (1990–2050) и нажмите **«Показать»**.
- Появится таблица: по каждому месяцу — рабочие дни, сокращённые
  (предпраздничные) дни и норма часов за месяц для недельных норм
  30 / 33 / 36 / 39 / 40 часов (Приказ № 588н).
- Ниже — норма за год и списки праздничных и сокращённых дней.
- Для годов вне точного диапазона 2020–2027 показывается метка
  **«требует сверки»** (постановления на будущие годы ещё не известны).

### 4.2. Импорт графика

1. Откройте вкладку **«Импорт графика (.xls)»**.
2. Выберите файл `.xls` (формат «СГП №16»). Период определяется автоматически
   из шапки; при необходимости укажите год и месяц явно.
3. Нажмите **«Импортировать»**.

Программа разберёт файл, классифицирует должности, пересчитает часы по каждому
сотруднику и запустит валидатор (5 типов ошибок). После импорта появятся:

- **Сводка** — сотрудники, дней в месяце, ошибки, предупреждения.
- **Кнопки экспорта** — CSV, Т-13, ОКУД 0504421, график на подпись.
- **Ошибки и предупреждения** — находки валидатора.
- **Сотрудники** — редактируемая таблица.
- **Инструменты** — автозаполнение и копирование графика.

## 5. Редактирование графика

- **Кликните** по ячейке дня, чтобы исправить значение. Вводите интервал вида
  `8-15,48` или код статуса (`В`, `ОТ`, `Б`, `У`).
- **Enter** — сохранить и перейти вниз; **Esc** — отмена.
- После каждого изменения пересчитываются часы, итоги и валидация.
- Нижний **«светофор»** подводит итог:
  - 🟢 **зелёный** — ошибок нет, можно выгружать;
  - 🟡 **жёлтый** — только предупреждения, выгружать можно;
  - 🔴 **красный** — остались ошибки, исправьте и выгрузите заново.

## 6. Инструменты

### Автозаполнение
Заполнить пустые ячейки сотрудника одной сменой:
1. Выберите сотрудника и введите смену (например, `8-15,48`).
2. Отметьте **«только рабочие дни»**, чтобы заполнять лишь рабочие дни по
   производственному календарю (иначе — все пустые, включая выходные).
3. Нажмите **«Заполнить»**.

### Копирование графика («врач ↔ медсестра»)
1. Выберите сотрудника-источник в поле **«Из»** и приёмника в поле **«В»**.
2. Нажмите **«Скопировать график»**. Весь месяц приёмника перезапишется
   сменами источника.

## 7. Экспорт

Все формы открываются в новой вкладке / скачиваются как HTML или CSV:

| Кнопка | Формат | Назначение |
| --- | --- | --- |
| График (CSV) | CSV с `;`-разделителем | исправленный график для Excel |
| Табель Т-13 | печатный HTML | табель учёта рабочего времени Т-13 |
| Табель ОКУД 0504421 | печатный HTML | табель для бюджетных организаций |
| График на подпись | печатный HTML | график на утверждение («УТВЕРЖДАЮ» / «СОГЛАСОВАНО») |

> Печатайте HTML-формы прямо из браузера (Ctrl+P).

## 8. Данные и конфиденциальность

- Персональные данные (152-ФЗ) хранятся **только локально**. Исходные файлы
  `.xls`/`.docx` исключены из git (см. `.gitignore`) и не покидают компьютер.
- Сессии **в памяти**: при закрытии сервера они удаляются. Чтобы продолжить,
  импортируйте файл заново.
